# Feedback

PokeNow is source-available ([PolyForm Noncommercial 1.0.0](LICENSE)) and maintained in this repository. Changes are made
here; **pull requests from outside aren't accepted**. Ideas, corrections and reports are very welcome as issues.

## Ways to help

- **Translation problems**: site footer → *Report a translation problem* (no GitHub account needed), or the
  [translation form](https://github.com/Churious/pokenow/issues/new?template=translation.yml). Copy the exact text you
  saw and how a native speaker would say it. Event names should match the game in your language; city and spot names
  stay in English on purpose.
- **A new hotspot**: *Suggest a hotspot* under the ranking on the site, or the
  [hotspot form](https://github.com/Churious/pokenow/issues/new?template=hotspot.yml). Include the coordinates and a
  public source for them (a map link or a community coordinate list).
- **A raid community** (free listing): the
  [community form](https://github.com/Churious/pokenow/issues/new?template=community.yml). Spoofing / GPS-change,
  account trading, bots and cheat tools aren't listed.
- **Bugs and ideas**: a [blank issue](https://github.com/Churious/pokenow/issues/new) with what you expected and what
  happened (device, browser, language).

Translation and community issues get an automatic first-pass review comment from an AI model (Gemini). It's advisory:
a maintainer checks every report before anything changes on the site.

Reports are public. Please leave out personal information.
